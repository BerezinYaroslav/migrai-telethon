# MIGR.AI Telegram Research

Read-only Telethon-сервис для поиска потенциальных респондентов CustDev по публичным миграционным сигналам в доступных аккаунту Telegram-чатах и каналах.

Сервис:

- читает список источников из Google Sheets или PostgreSQL;
- читает сообщения и доступные списки реакций через MTProto;
- применяет прозрачный rule-based скоринг;
- сохраняет только короткий фрагмент релевантного сообщения;
- дедуплицирует сигналы и кандидатов в PostgreSQL;
- при необходимости выгружает кандидатов в отдельный лист Google Sheets.

Сервис **никому не пишет в Telegram**. В коде нет команд отправки сообщений, реакций, вступления в чаты или приглашения пользователей. Контакт с респондентами команда осуществляет вручную вне этого приложения.

## Стек

- Python 3.10+
- Telethon 1.x
- PostgreSQL 16
- SQLAlchemy 2 + asyncpg
- Alembic
- Pydantic Settings
- Google Sheets API
- Typer CLI

## Быстрый старт

1. Создайте окружение и установите проект:

   ```bash
   python3 -m venv .venv
   .venv/bin/pip install -e '.[dev]'
   ```

2. Скопируйте пример настроек:

   ```bash
   cp .env.example .env
   ```

3. Запустите PostgreSQL:

   ```bash
   docker compose up -d postgres
   ```

4. Примените миграции:

   ```bash
   .venv/bin/migrai db upgrade
   ```

5. Проверьте локальный скоринг без Telegram:

   ```bash
   .venv/bin/migrai score "Кто подавался на ВНЖ Испании по digital nomad и можно ли с супругой?"
   ```

6. После создания отдельного Telegram-аккаунта заполните `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`, затем выполните первый скан:

   ```bash
   .venv/bin/migrai scan --sync-sheets --export-sheets
   ```

При первом подключении Telethon интерактивно запросит номер, код и 2FA-пароль. Файл сессии создаётся в `var/sessions/` и исключён из Git.

## Google Sheets

Для интеграции нужен service account JSON. Таблицу необходимо вручную предоставить email этого service account с правами:

- чтение — для листа источников;
- редактирование — только если нужна выгрузка кандидатов.

Путь к ключу задаётся в `GOOGLE_SERVICE_ACCOUNT_FILE`. Названия колонок источников настраиваются через переменные `SHEETS_SOURCE_*_COLUMN`, поэтому сервис не зависит от фиксированных букв столбцов.

Рекомендуемая структура:

- `Каналы и чаты` — исходная база;
- `Потенциальные респонденты` — автоматическая выгрузка;
- `Люди` — ручная база тех, с кем команда действительно начала контакт.

## Команды

```bash
migrai db upgrade                   # применить миграции
migrai db current                   # показать текущую миграцию
migrai score "текст"                # проверить скоринг локально
migrai sources sync                # синхронизировать источники из Sheets
migrai scan                        # прочитать доступные источники
migrai candidates export           # выгрузить кандидатов в Sheets
migrai doctor                      # проверить конфигурацию без подключения к Telegram
```

## Безопасные границы

- Только источники, уже доступные аккаунту. Автовступления отсутствуют.
- Только чтение Telegram. Исходящие действия отсутствуют.
- Реакция — слабый сигнал и сама по себе не делает человека кандидатом высокой уверенности.
- Слабые сигналы реакций хранятся для агрегации, но не экспортируются без достижения порога кандидата.
- Комментарии читаются только у релевантных постов и с отдельным лимитом на пост.
- Не сохраняются политические взгляды, здоровье, религия, интимные сведения, полная история сообщений или медиа.
- Политический контекст без явного миграционного намерения исключается скорингом.
- Текст доказательства обрезается до `SIGNAL_EXCERPT_MAX_CHARS`.
- `FloodWaitError` соблюдается; ограничения Telegram не обходятся.
